# @integrations/search-commerce

Search served by the commerce platform itself. `CommerceSearchProvider` adapts the commerce integration's product search (`productSearchService`) to the search contract: no index, no sync and no vendor code, so it works with any commerce integration (commercetools, the mock, any other). Choose a search engine (Algolia, …) instead when the shop needs one.
